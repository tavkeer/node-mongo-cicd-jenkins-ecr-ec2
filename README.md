# DevOps Node Mongo Base Project

This is a minimal Node.js and MongoDB application designed as a reusable base project for DevOps practice.

## Features
- Express-based API
- MongoDB connection with retry logic
- Health check endpoint
- Simple notes API
- Dockerfile for containerization
- Docker Compose for local multi-container setup

## Endpoints
- GET /
- GET /health
- GET /api/notes
- POST /api/notes
